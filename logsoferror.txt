This is why invoices are not displaying on the customer profile invoice tab


Root Cause: customer_id is NULL on all invoice records

The query in CustomerProfiles.tsx filters invoices using:


.eq('customer_id', customer.id)
But looking at the actual data in printavo_invoices, the customer_id column is NULL on every single invoice row. The invoices do have customer_name stored, but no UUID link back to the customers table was ever populated.

This means the query returns zero rows every time, resulting in the "No invoices found" empty state.

Plan: Fix Invoice Display in Customer Profile

1. Fix the Invoice Query (Short-term)

Update the loadCustomerInvoices function to query invoices by matching customer_name (from printavo_invoices) against the customer's company_name (from the customers table), instead of the broken customer_id match
This gets invoices displaying immediately using data that is already populated
2. Backfill customer_id on Existing Invoices (Long-term data fix)

Run a SQL update that joins printavo_invoices with customers on customer_name = company_name to backfill the missing customer_id values on all existing invoice rows
This makes the proper UUID-based foreign key relationship work going forward
3. Fix the Invoice Creation/Sync Logic

Find where invoices are created or synced into the printavo_invoices table and ensure the customer_id UUID is correctly written at creation time, so future invoices do not have this same problem
This is a straightforward two-part fix: an immediate query change to unblock the UI, plus a data backfill and source fix to set up the correct relationship long term.
